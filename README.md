## 02 · LoomLoop

### Yarn-Tension and Loom-Diagnostics Prototype

> **Current status: requirements definition. No working prototype or field
> result is claimed yet.**

I am developing a low-voltage experimental system that studies whether
affordable sensors and embedded control can help identify yarn-tension variations
and weaving interruptions.

The planned laboratory prototype investigates:

- Load-cell tension measurement
- Motor and encoder feedback
- Vibration and motion sensing
- Microcontroller-based data acquisition
- Closed-loop tension control
- Signal processing and anomaly detection
- A removable, read-only sensor pod for supervised handloom trials

The aim is not to automate or replace the artisan. It is to investigate whether
useful, privacy-preserving feedback can reduce troubleshooting time and avoidable
material waste. Schematics, calibration data, control results, unsuccessful
experiments, safety precautions, and field observations will be published only
as they become real and reproducible.

## 03 · BaitWatch

[BaitWatch](https://github.com/sreekarseera/baitwatch) is a privacy-first browser
extension that explains likely scam and social-engineering signals in messages
and web pages. Detection runs locally by default.

behavior, known limitations, and failure cases rather than relying on an

## How I approach engineering

1. Start with a real user and a clearly defined problem.
2. Document requirements, constraints, risks, and success criteria.
3. Build the smallest safe prototype that can answer the main question.
4. Calibrate sensors and compare measurements against references.
5. Test normal operation, edge cases, and failure conditions.
6. Report unsuccessful experiments as well as successful ones.
7. Improve the system using evidence rather than assumptions.
8. Credit mentors, collaborators, libraries, datasets, and AI assistance.

> **Build only what can be explained. Measure before claiming. Publish limits
> alongside results.**
